# **App Name**: Connectify

## Core Features:

- User Authentication: Secure user registration and login.
- Profile Management: Users can create and edit their profiles, including uploading a profile picture and adding a bio.
- Post Creation: Users can create and share posts with text and images.
- Like Functionality: Users can like posts.
- Commenting System: Users can comment on posts.
- Follow/Unfollow: Users can follow other users.
- News Feed: Display posts from users that the current user follows.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to convey trust and connection.
- Background color: A light gray (#F5F5F5) to provide a clean and modern look.
- Accent color: An energetic orange (#FF8C00) to highlight interactive elements and calls to action. 
- Font pairing: 'Poppins' (sans-serif) for headlines, and 'PT Sans' (sans-serif) for body text to combine modernity and readability.
- Use a consistent set of outline icons for key actions (like, comment, share) and profile elements.
- Implement a clean, intuitive layout with a focus on readability and easy navigation. Use a card-based design for posts to visually separate content.
- Subtle transitions and animations for user interactions, such as likes and comments, to enhance the user experience.
